# Improved Security Risk Assessment Tool (TL 12-11)

## At a glance

## Full text

CALIFORNIA TECHNOLOGY AGENCY                                      NUMBER:          DATE ISSUED:

TECHNOLOGY LETTER                                                 TL 12-11         AUGUST 8, 2012
SUBJECT:                                                          REFERENCES:
IMPROVED SECURITY RISK ASSESSMENT TOOL                            Government Code 11549.3.(6)
Improve and automate the Information Security Assessment
Tool for State Agencies

BACKGROUND

In April 2008, the California Office of Information Security (OIS) published an Information Security
Assessment Tool for State Agencies. The assessment tool was built in Microsoft Word and is part of a
Risk Assessment Toolkit on the OIS website used by state agencies to assess the maturity of their
information security program functions.

PURPOSE AND DESCRIPTION

The purpose of this Technology Letter (TL) is to communicate an update of the Information Security
Assessment Tool for State Agencies. The upgraded tool improves the ease with which security
assessments are documented and scored by using a Microsoft Excel workbook with added formulas to
automatically calculate a risk score for assessed information security functional areas.

PROCESS
Agencies and departments are encouraged to use this improved assessment tool when performing a
self-assessment of their organization’s information security posture. The categories and descriptions
within the tool are the same as the 2008 version, therefore, those that have used it will be familiar with
the content. For assistance using this tool, please contact Marianne Chick at (916) 431-5584 or
Marianne.Chick@state.ca.gov.

QUESTIONS

Questions regarding this TL may be directed to Michele Robinson, Chief Deputy Director, Office of
Information Security, at (916) 445-5239 or Michele.Robinson@state.ca.gov.
