# Enterprise Zscaler Implementation (State CISO Memorandum, 2023-07-13)

## At a glance

Sets zero-trust network access as one enterprise implementation managed by Cyber Security Services and holds agency-level plans.

## Full text

                                                                            Enterprise Information Services
                                                                                         Cyber Security Services
                                                                                    550 Airport Road SE, Suite C
                                                                                                Salem, OR 97301
                                                                                                    503-378-2282

MEMORANDUM
To:            Agency IT Leadership

From:          Ben Gherezgiher, State Chief Information Security Officer

Date:          July 13, 2023

Subject:       Enterprise Zscaler Implementation

As we all strive to elevate the security posture of the State of Oregon, there is increasing interest
in implementation of a Zero Trust Network Access (ZTNA) strategy to modernize remote access
capability and update the underlying network architecture to meet business and security needs. To
that end, Enterprise Information Services (EIS) has begun to set the course for a standards-based
set of technology projects to implement mature, sustainable solutions using appropriately planned
technology.

One of the product solutions included in the enterprise ZTNA strategy is Zscaler. This product has
been in controlled pilot testing in select agencies with promising results. While some agencies are
anxious to procure and deploy such tools, it is important that efforts are approached in an organized
fashion. ZTNA will move forward as an enterprise solution with one tenant, with full consideration
given to economies of scale, consistent maintenance, enhanced security monitoring and access
control.

EIS is planning two efforts that will modernize our network and network security:

   •    Network Security Modernization Project which includes ZTNA strategy.
   •    M365 Security Enhancements Project which includes security reference architecture and
        an associated M365 security enhancement roadmap.

Enterprise ZTNA will be rolled out as a cloud-based enterprise project managed by EIS Cyber
Security Services. Among other benefits, this project will retire our outdated VPN technology.

At this time, except for a limited pilot implementation at the Governor’s Office, all other agency
plans are delayed until the near-term Enterprise plans are complete. Additional information
regarding timelines and sequence of implementation strategy will follow through project updates.

               Mission: Mature enterprise technology governance, optimize investments, ensure
                transparency, provide oversight, and deliver secure and innovative solutions.
