# Information Security Committee Charter (S.2.03.01)

## At a glance

Listed on the Governor's Technology Office page 'Security Policies, Standards & Procedures' (https://it.nv.gov/governance/security-policies-standards--procedures/) as 'S.2.03.01 - State Security Committee Charter - Effective 12/31/2020'. NAC 242.110 adopts the State Information Security Policies, Standards and Procedures by reference and binds every executive-branch agency, state employee and contractor with access to state information to them. Charter of the State Information Security Committee: its mission as the advisory body that develops state-level information security policy and standards, its sponsor and chair, and its responsibilities.

1.0     PURPOSE
        This chapter establishes the State of Nevada, State Information Security Committee.

2.0     MISSION
        The State Information Security Committee is established to facilitate interaction between state
        departments, divisions, boards, and commissions on identifying and addressing information
        security related policies, standards, problems, and issues.

        The secondary mission of the Committee is to serve as an advisory committee participating in
        development of common information security policy and standards at the State level, regardless
        of technology platform or agency size, and to assist in promoting State level Information Security
        Standards. All established and new information security policy and standards are to assist and
        provide guidance in providing a common direction to state agencies in developing individualized
        Information Security Programs consistent with their IT operating environment.

3.0     LIFE SPAN
        The State Information Security Committee will exist indefinitely.

4.0     RESPONSIBILITIES
        4.1   The State Information Security Committee is sponsored by Enterprise IT Services (EITS)
              and will be chaired by the State Chief Information Security Officer (CISO).

        4.2   The responsibilities of the Information Security Committee shall include:

              A. Serve as an advisory committee to the State on IT security issues.
              B. Establish state level information security policy and standards.
              C. Identify, review, and resolve state level information security problems and issues.
              D. Function as a working body to define and develop common information security policy
                 and standards that will apply to all agencies, all IT platforms, and the processing and
                 security of electronic records.
              E. Promote information security understanding and awareness throughout the State,
                 particularly members’ respective agencies.
