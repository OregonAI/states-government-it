# Software Use (WyIT 3018)

## Full text

                            SOFTWARE USE
                                     WyIT 3018

PURPOSE: This policy outlines the requirements for software installation on State of
Wyoming computing devices; minimizing risks of losing program functionality, exposure
of sensitive information contained within the state computing network, introduction of
malware, and legal requirements for using licensed software.

 I.​ APPLICABILITY

    This policy applies to all Executive Branch agencies, boards, and commissions staff
    (collectively referred to as “agencies”). This policy is also applicable to consultants,
    affiliates, and temporary employees.

II.​ DEFINITIONS

    All definitions for this policy are located in the Policy Dictionary.

III.​ EXCEPTIONS

    Any exceptions provided to the following policy must abide by the WyIT - 3002 -
    Security Exception Request policy.

IV.​ REQUIREMENTS

    All applicable agencies and/or affiliates identified in the scope of this policy are not
    permitted to install software on the State of Wyoming equipment without express
    permission from the CIO. Employees who install software on enterprise computing
    devices expose the state to vulnerabilities, including but not limited to software
    incompatibilities and support issues, cybersecurity attacks such as malware and
    ransomware, and liability issues associated with unlicensed software versions.

        ●​ Prior to any software installation, a request for approval shall be coordinated
           with the respective agency security contact.
        ●​ The agency security contact will create a service request in the CIO online
           ticketing solution.
        ●​ Under normal, non-emergency operations, the CIO will examine the software
           solution through an industry-standard vetting process within 30 days of
           submission. Any legacy business applications with known vulnerabilities must be
           accompanied by a security exception request.
        ●​ Installation of approved software must be performed by an authorized member
           of the CIO Customer Support Division. Exceptions will be evaluated on a
           case-by-case basis.
        ●​ Software licenses purchased through the respective agency will be tracked and
           managed by the agency. Software licensing associated with the state enterprise
           will be tracked and managed by the CIO.
        ●​ Software designated as free for individuals, home use, Freeware, and or
           Shareware is not authorized within the state’s enterprise.
        ●​ Exceptions may be evaluated on a case-by-case basis.​

  V.​   SECURITY TOOLS

        No security tool will be run within the state enterprise without written
        authorization from the CIO. Authorization is obtained through a security
        exception request. Examples of security tools include, but are not limited to:

        ●​ Anti-virus tools are not specifically authorized by the CIO.
        ●​ Malware removal tools not specifically authorized by the CIO.
        ●​ Tools designed to intercept and allow inspection of network traffic.
        ●​ Tools designed to conduct scans of devices on the network.
        ●​ Tools designed to encrypt data.

 VI.​   “HACKING” TOOLS

        Tools designed to perform any action attempting to identify or subvert the security
        of the state shall not be used.

REFERENCES: This policy has no supporting references to websites, other policies, or
federal or state statutes.
