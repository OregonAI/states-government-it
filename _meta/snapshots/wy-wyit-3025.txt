                    SOURCE CODE CONTROL POLICY
                                           WyIT - 3025

  PURPOSE:        This policy describes procedures and standards for the ownership,
  storage, and management of uncompiled computer programming code files.

  I.   APPLICABILITY

       This policy applies to all Executive Branch agencies, boards, and commissions staff
       (collectively referred to as “agencies”). This policy is also applicable to consultants,
       affiliates, and temporary employees.

 II.   DEFINITIONS

       All definitions for this policy are located in the Policy Dictionary.

III.   EXCEPTIONS

       Any exceptions provided to the following policy must abide by the WyIT - 3002 -
       Security Exception Request policy.

IV.    ROLES

       ● Developer: Any affiliate, State Employee, AWEC, contractor, or other who
         creates computer program files on behalf of a State Agency, Board, or
         Commission.
       ● Source Code Manager: State employee that controls the process, application, or
         program associated with a collection of source code.
       ● Code Repository Manager: ETS employee who manages the Enterprise code
         repository solution.

  V.    APPOINTMENT OF SOURCE CODE MANAGER

        Upon receipt of an ETS Service Request, the Code Repository Manager will
        establish a new project in the code repository with permissions establishing the
        requestor as the Source Code Manager.

 VI.    SOURCE CODE MANAGER RESPONSIBILITIES

        ● Source Code Managers perform access control duties for their respective
          project personnel, authorizing developer access to their respective programs’
          code. They add, change, and delete developers on their segment of the code
          repositories.
        ● It is the Source Code Manager’s responsibility to ensure that the developers with
          access to their project commit code on a timely basis. They also need to ensure
          that the source code in the code repository is always current and is the system
          of record for their program.
        ● Source Code Managers are responsible for ensuring developers with access to
          their projects have appropriate security training.
        ● Data, in any form, is not to be housed in the code repository.

VII.    SOURCE CODE MANAGEMENT

        ● All Source Code generated by state employees or by public affiliates acting
          under agreements with the State of Wyoming is owned by the State of Wyoming.
        ● All Source Code owned by the State of Wyoming must be stored in the
          Enterprise Source Code Repository solution.
        ● The Source Code Repository is the system of record for all State of Wyoming
          source code and associated applications or programs.
        ● All repositories in the Enterprise Source Code Repository for the State of
          Wyoming must be accessible within the state domain only.
        ● All personally owned repositories previously used will be disallowed, and code
          will be migrated to the Enterprise source code repository solution.

VIII.   SOURCE CODE REPOSITORY MANAGER RESPONSIBILITIES

        ● The Source Code Repository Manager is responsible for maintaining the Code
          Repository solution provided by ETS.
        ● The Source Code Repository Manager creates projects and grants permissions

        to Source Code Managers upon request.
      ● The Source Code Repository Manager conducts an annual review of all code
        repository accounts and provides the report to the respective Source Code
        Managers.
      ● The Source Code Repository Manager conducts and logs an annual review of
        the Source Code Control Policy.
      ● The Source Code Repository Manager provides operational functionality training
        for Source Code Managers for the Code Repository.

IX.   REVIEWS

      ● Reviews of this Document
        ○ This document and associated procedures are to be reviewed each calendar
           year by the Source Code Repository Manager. A log will be kept by the
           Source Code Repository Manager with the date of review and initials of the
           reviewer.
        ○ Changes to this document will be approved by ETS and the CIO.
      ● Audit of Accounts for Compliance
        ○ Additional account reviews may be conducted by the Code Repository
           Manager.

X.    SOURCE CODE REPOSITORY

      The Source Code Repository solution is provided and supported by ETS. The
      solution follows accepted industry standards and provides secure storage.

XI.   SECURITY AWARENESS AND TRAINING

      ● Security awareness training is based on the security requirements of agencies’
        systems and may vary by agency and system. Source Code Managers are
        responsible for ensuring developers with access to their project have
        appropriate security training.
      ● ETS will provide operational function training for the Source Code Repository.

REFERENCES: This policy has no supporting references to websites, other policies,
federal or state statutes.
