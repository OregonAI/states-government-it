                                                       DEFINITION
Name                     Production, Input and Output Controls
                         Production, input and output controls are the security procedures in place that support the
                         operations of the information technology system. Some examples are: user support;
Description              procedures to ensure unauthorized individuals cannot read, copy, alter, or steal printed or
                         electronic information; internal and external labeling of media; and procedures for
                         restricting access to output products.
                         Agencies need a strong, disciplined, clearly defined approach to production, input and
Rationale                output controls. This helps assure the confidentiality, availability and integrity of the data
                         maintained by those systems.

                         • Assists with the security of sensitive and mission-critical application systems of
