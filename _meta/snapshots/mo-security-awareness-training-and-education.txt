                                                    DEFINITION
Name                Security Awareness Training
                    Security Awareness Training is the basic understanding of the need for
Description         information security and user actions to maintain security and to respond to
                    suspected security incidents.
                    Security Awareness Training teaches employees how to protect information technology
                    systems and agency data. Additionally, Security Awareness Training develops skills and
Rationale
                    knowledge enabling employees to perform their jobs more securely and build in-depth
                    knowledge.
                        • Improves security posture of the enterprise
Benefits
                        • Facilitates the implementation of appropriate security policies and procedures
