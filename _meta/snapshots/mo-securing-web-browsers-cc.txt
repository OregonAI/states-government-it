                                                      DEFINITION
Name                   Securing Web Browsers
                       Securing Web Browsers refers to configuring the user interface to the World Wide Web in
Description            order to minimize vulnerabilities and exposure from external threats.
                       This document does not address securing the internal use of web browsers (Intranets).
                       Securely configuring Web Browsers reduces risks to the agency network when accessing
Rationale
                       information on the World Wide Web.
                           Protects the confidentiality, integrity and availability of the agency data and network
Benefits                   Prevents the downloading of unauthorized software
                           Provides options to preserve privacy
