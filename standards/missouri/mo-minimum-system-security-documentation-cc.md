                                                         DEFINITION
Name                   Minimum System Security Documentation
                       Minimum System Security Documentation contains the system life cycle and descriptions of
Description            the system hardware, software, policies, standards, procedures, and approvals related to
                       information systems.
                       The documentation of hardware, software, policies, standards, and procedures provide the
                       basis for protecting the integrity, availability, and confidentiality of each of an agency’s IT
Rationale
                       resources. This documentation explains how software and hardware is to be used and
                       serves to formalize the security and operational controls specific to agency’s systems.
                            • The availability of formal resource security documentation will aid in ensuring that
                               each systems operational activities are understood
Benefits
                              •   Formalized documentation of operational practices and procedures helps to
                                  eliminate security lapses and oversights

                                               Documentation and Technical Considerations CC)
                                         o Risk Assessment (see Risk Assessment CC)

                                         o     Documentation for in-house applications
                                         o     Detailed documentation on operation of networks, routers, and

                                         o     Software and hardware acceptance testing procedures and results

                                        o Is considered a sensitive document and must be protected accordingly
