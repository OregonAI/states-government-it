# Software Inventory and Control (S.6.02.01)

## At a glance

Listed on the Governor's Technology Office page 'Security Policies, Standards & Procedures' (https://it.nv.gov/governance/security-policies-standards--procedures/) as 'S. 6.02.01 - Software Inventory and Control - Effective 12/31/2020'. NAC 242.110 adopts the State Information Security Policies, Standards and Procedures by reference and binds every executive-branch agency, state employee and contractor with access to state information to them. Inventory and control of software assets (CIS Controls).

1.0   PURPOSE
      This standard establishes the minimum requirements for inventory and control of software assets,
      as required to implement the CIS Controls v7.1, Implementation Group 1.

2.0   SCOPE
      This standard applies to all state agencies and authorized users meeting the criteria identified in
      the State Information Security Program Policy, Section 1.2, Scope and Applicability.

3.0   EFFECTIVE DATES
      This standard becomes effective at the time of approval of the State Chief Information Officer
      (CIO).

4.0   RESPONSIBILITIES
      The agency head and appointed Information Security Officer (ISO) have the responsibility to
      ensure the implementation of and compliance with this standard.

5.0   RELATED DOCUMENTS
      State Information Security Program Policy, 100
      Information Security Officer (ISO) Roles and Responsibilities, S.3.03.01
      Mobile and Non-State Device Security, S.4.02.02

6.0   STANDARD
      6.1     State agency management is responsible for establishing and monitoring inventory and
              control procedures for all agency software, ensuring compliance with all software licenses.

      6.2     Only state agency authorized software shall be installed or used on state hardware assets.
              The use of unlicensed software (software used in violation of the software license) or
              agency-unauthorized software is strictly forbidden.

      6.3     All requests for non-standard software require approval authorization from the appointed
              agency ISO.

      6.4     Each agency shall establish and maintain a software inventory to track and control all
              applicable software installation images or media; licenses or end user license agreements;
              certificates of authenticity; documentation; and related items.

      6.5     Each agency shall establish and maintain a software library or libraries to control access to
              all software installation images or media; licenses or end user license agreements;
              certificates of authenticity; documentation; and related items. The library(s) shall be located
              in a secure area. The library(s) shall include all copies of software licenses, images, and
              media, and at least one copy of the manual and other documentation.

      6.6     The agency shall conduct a software audit and annual inventory of the libraries and
              computer systems to determine whether the agency is complying with applicable software
              license agreements, and with Federal, State, and Agency standards and procedures. The

          Technology Assets: As defined in CIS Controls v7.1, the term “Technology Assets” (also
