I.      AUTHORITY

        Authority:    Idaho Code § 67-833

II.     ABSTRACT

        The purpose of this guideline is to ensure logical and consistent presentation of
        web-based materials and services while conforming to federal guidelines for
        accessibility by users with disabilities. The requirements of this guideline apply to
        all public-facing web pages registered under the idaho.gov domain.

III.    DEFINITIONS

        See ITA Enterprise Guideline G105 (Glossary of Terms) for any definitions.

IV.     HOSTING AND DEVELOPMENT GUIDELINES

        A.     Non-E-commerce Hosting
               State agencies may choose from any of the following options for the
               physical placement of standard (non-E-commerce) websites and web
               applications. An agency may:

             1.     Use the centralized hosting services that the Office of Information
                    Technology Services (ITS) provides.

             2.     Contract with another State of Idaho agency for the hosting
                    services;

             3.     Setup, install, and maintain its own web server(s) for the hosting
                    services; or,

             4.     Contact ITS for the current list of State-approved vendors to
                    provide hosting services.

      B.     E-commerce Hosting
             State agencies may choose from any of the following options for physical
             placement of E-commerce web applications. E-commerce web
             applications are those that involve the collection of credit card types of
             information and/or the actual electronic transfer of monies and/or funds.
             An agency may:

             1.     Setup, install, and maintain its own Internet web server(s) for the
                    hosting of its PCI-compliant E-commerce web applications; or,

             2.     Contact ITS for the current list of State-approved PCI-compliant E-
                    commerce vendors, and contract with one or more of those
                    vendor(s) for the hosting of its E-commerce web applications.

      C.     Web Page, Website, and Web Application Development – State of Idaho
             agencies have the following options for the development of Internet web
             pages, websites, and/or web application development. An agency may:

             1.     For new or replacement websites or web application development,
                    submit an ITS Website Services Request on the ITS website;

             2.     For minor website or web application requests, submit a Website
                    Request catalog item in the ITS Service Desk system;

             3.     Use its own in-house personnel for web page, website, and/or web
                    application development;

             4.     Contract with another State of Idaho agency for web page, website,
                    and/or web application development; or

             5.     Contract with a State-approved vendor to provide web page,
                    website, web application, web development, and/or web
                    maintenance. Contact ITS for a current State-approved vendor list.
