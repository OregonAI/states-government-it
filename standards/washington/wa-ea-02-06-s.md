PURPOSE
This standard establishes the statewide service capability, Secure Connections, as an enterprise
service under EA-02 – Establishing an Enterprise Service Policy. A Washington state agency
must not adopt, build, expand, or renew a service with similar capabilities unless it has an
approved waiver or exemption (see Section 5).

SCOPE
The Secure Connections service capabilities listed in Section 4 must be used to access internal
state resources. This enterprise service protects state network resources, systems, and data.

APPLICABILITY
This standard applies to all state agencies (as defined in RCW 43.105.020) and their
organizational users (including employees, contractors, partners, and vendors).
This standard does not apply to the K-20 network, institutions of higher education, legislature,
judiciary, or local governments.

ENTERPRISE SERVICE CAPABILITIES
The Secure Connection enterprise service designation encompasses the following capabilities:
     1. Cloud Virtual Private Network (VPN) – provides a secure way to connect state employees
        to agency applications and other services hosted in a public cloud network using an
        Internet connection.
     2. Internal Certificate Authority (ICA) – provides centrally governed trusted digital
        certificates for use inside the State Government Network (SGN) to address the need to
        protect data in transit.
     3. Managed Firewall as a Service (FWaaS) – protects agency networks, systems, and
        workloads from unauthorized access and malicious attacks.
     4. Office VPN (weblink) – provides a secure, cost-effective way to connect state employees
        to an agency's main network through a local Internet Service Provider (ISP).

                                                                                                   1

   5. Security Service Edge (SSE) – enterprise-managed security and access capability that
      delivers consistent, policy-based protection and secure connectivity for users, devices,
      and applications across on-premises, cloud, and remote environments.
   6. User Virtual Private Network (SSL VPN) – provides remote users with secure Internet
      access to agency networks from any location.

WAIVERS AND EXEMPTIONS TO THIS STANDARD
In accordance with POL-01-02-S Technology Policy and Standard Waiver Request Standard,
agencies may qualify for a waiver from compliance with this standard. No categorical
exemptions apply.

AUTHORITY
This standard is issued under the authority of RCW 43.105.054, which grants Washington
Technology Solutions authority to establish statewide technology standards and enterprise
services. RCW 43.105.006 establishes Washington Technology Solutions as the centralized
provider of broadly used and uniform technology services. RCW 43.105.450 requires state
agencies to comply with statewide information technology security policies and standards.
