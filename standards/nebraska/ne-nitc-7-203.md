# 7-203. IP communication protocol standard for synchronous distance learning and videoconferencing over Network Nebraska. (NITC Technical Standards and Guidelines 7-203)

## At a glance

NITC Technical Standards and Guidelines section 7-203, adopted by the Commission under Neb. Rev. Stat. 86-516 and applying to state agencies, boards and commissions (1-102).

## Full text

                                                                               Nebraska Information Technology Commission
                                                                                          Technical Standards and Guidelines

7-203. IP communication protocol standard for synchronous distance learning and
videoconferencing over Network Nebraska.
    (1) Purpose. The purpose of this standard is to implement a consistent communication
protocol to be used by all entities wishing to pass synchronous, interactive teleconference video
over Network Nebraska.
   (2) Standard. All state agencies, entities that receive state funding for telecommunications,
and entities that wish to pass synchronous video over Network Nebraska must use IP as their
communication protocol for synchronous video.
